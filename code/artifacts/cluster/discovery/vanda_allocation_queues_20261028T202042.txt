== hpc interactive

 ===================================================
   Open An Interactive Job in Vanda Cluster Node
 ===================================================

 ---------------------------------------------------------------
  To start an interactive command line interface in a CPU node
 ---------------------------------------------------------------

 Enter this pbs command in login node:

   [vanda-login-01]> qsub -I -l select=1 -l walltime=02:00:00 -P <projectid> 

   where 
         -I                   :  Launch an interactive session
         -l select=1          :  Request for 1 CPU socket, 36 cores, 250gb memory by default
                                 To request for a full node (2 CPU sockets), use select=2
         -l walltime=**       :  Request walltime, max up to 12 hours
         -P projectid         :  Specify which project that be used for credits

   After enter the command, you should see your prompt change to NUS-ID@cn-XXX, indicates a CPU node.


 ---------------------------------------------------------------
  To start an interactive command line interface in a GPU node
 ---------------------------------------------------------------

 Enter this pbs command in login node:

   [vanda-login-01]> qsub -I -l select=1:ngpus=1 -l walltime=02:00:00 -P <projectid> 

   where 
         -I                   :  Launch an interactive session
         -l select=1:ngpus=1  :  Request for 1 CPU socket, 36 cores, 250gb memory, 1 GPU by default
                                 To request for a full node (2 CPU sockets, 2 GPUs), use select=2:ngpus=1
         -l walltime=**       :  Request walltime, max up to 12 hours

   After enter the command, you should see your prompt change to NUS-ID@gn-a40-XXX, indicates a GPU node.


 ------------------------------------------------------------------------
  NOTE: If -P <projectid> not provided, will default to personal credits 
 ------------------------------------------------------------------------
